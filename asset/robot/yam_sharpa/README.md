# Robot description used by the render tool

* `yam_sharpa_left.urdf`, `yam_sharpa_right.urdf`: the two arm-plus-hand assemblies the renderer replays (assembled for this project).
* `meshes/yam/`: the meshes of the I2RT YAM arm, from https://github.com/i2rt-robotics/i2rt (MIT, copyright I2RT; license below).
* `meshes/left_hand/`, `meshes/right_hand/`: the meshes of the Sharpa Wave hand, from https://github.com/sharpa-robotics/sharpa-urdf-usd-xml; see that repository for its license terms (Sharpa Robotics).

These files are redistributed only so that the clips can be re-rendered; they are not covered by this project's MIT license.
